# Tube Switch

Локальный обход DPI для macOS с переключателем в строке меню.
Без VPN-подписки и внешнего прокси-сервера. Использует `tpws` из zapret.

[Скачать из GitHub Releases](https://github.com/kazak/macdpi/releases)

## Возможности

- Включение и выключение из строки меню; **⌥-клик** переключает режим сразу.
- Выбор сервисов по отдельности и сохранение выбранного режима.
- Автозапуск при входе в учётную запись.
- Сохранение прежних сетевых настроек и возможность их восстановить.
- Universal-приложение для Apple Silicon и Intel.

## Сервисы

| Профиль | По умолчанию | Область применения |
|---|---|---|
| YouTube | Включён | Сайт и видео через TCP. Проверен на исходной тестовой сети |
| Discord | Включён | Веб-версия, чат и вложения; голос через UDP не поддерживается |
| Twitch | Выключен | Дополнительный профиль для сайта и трансляций через TCP |
| SoundCloud | Выключен | Дополнительный профиль для сайта и аудио через TCP |

Профиль означает набор доменов для обработки, а не гарантию доступности.
Результат зависит от провайдера и способа блокировки. Discord, Twitch и SoundCloud
нужно проверять в своей сети. Программы, игнорирующие системный прокси, могут потребовать
отдельной настройки; в первую очередь проверяйте веб-версии сервисов.

Instagram удалён из профилей: текущая реализация не обеспечивает его доступность.

## Требования

- macOS 13 Ventura или новее.
- Apple Command Line Tools с Python 3.9+ для локального сервиса.
  Если они ещё не установлены: `xcode-select --install` в Terminal.
- Права администратора нужны для первого подключения и полного восстановления
  сетевых настроек. При обычном переключении пароль не запрашивается.

Текущая сборка использует Python из Command Line Tools и не является приложением
без внешних системных зависимостей.

## Установка и использование

1. Скачайте ZIP из Releases и распакуйте его.
2. Откройте `Tube Switch.app`. Оно сохранит себя в `~/Applications`.
3. На новом Mac выберите в меню «Настроить подключение…» и выполните первоначальную
   настройку в Terminal. На Mac с предыдущей версией конфигурация сохраняется.
4. Выберите нужные пункты в меню «Сервисы» и проверьте воспроизведение/чат в браузере.

Чтобы полностью вернуть прежнее подключение: **Дополнительно → Вернуть прежние сетевые настройки…**.
«Скрыть значок» оставляет приложение и выбранный режим работать в фоне.
Для возвращения значка снова откройте приложение.
Для обновления завершите Tube Switch через меню, затем откройте новую сборку.
«Завершить Tube Switch» останавливает приложение и его локальный сервис.

Сборки без Developer ID не нотаризованы Apple. Процесс подписи и подготовки публичного
релиза описан в [docs/RELEASING.md](docs/RELEASING.md).

## Как это работает

Системный PAC направляет домены встроенных профилей в SOCKS на `127.0.0.1:10888`.
Для выбранных сервисов tpws изменяет разбиение TCP/TLS-пакетов. Отключённые профили
передаются тем же локальным сервисом без обработки DPI. Поэтому изменение выбора
сервисов не требует повторного ввода пароля или обновления системного PAC.

Остальные домены подключаются напрямую. При недоступности локального сервиса PAC
разрешает прямое подключение. Это не kill switch и не средство сокрытия IP.
HTTPS-сертификаты не устанавливаются; HTTPS остаётся зашифрованным между клиентом и сайтом.

`tpws` не обрабатывает UDP/QUIC, не даёт зарубежный IP и не устраняет блокировки по IP.
Голосовые каналы Discord этим приложением не обходятся. Сайты с ECH и иными способами
шифрования имени хоста могут не соответствовать доменным фильтрам.

Управление доступно только на loopback. Изменения требуют локального случайного токена;
история посещений и пользовательские данные в логи не записываются.

## Сборка и тесты

```sh
python3 scripts/build.py
TPWS_BIN="$PWD/dist/Tube Switch.app/Contents/Resources/tpws" python3 -m unittest discover -s tests -v
python3 scripts/audit.py --artifacts dist/*.zip
```

Результат: `dist/Tube-Switch-1.1.0-universal.zip`, архив исходников и `SHA256SUMS.txt`.
Сборка использует включённые исходники tpws, зафиксированные по commit и SHA-256;
скачивание изменяемой ветки `master` не требуется.

GitHub Actions проверяет сборку на pull request. Тег, совпадающий с `VERSION`, создаёт
черновик GitHub Release с артефактами. Публичная публикация остаётся отдельным действием.

## Разработка

- `Sources/main.swift` — меню macOS, установка, миграция и управление сервисом.
- `Sources/agent.py` — PAC, SOCKS-процесс и локальный API.
- `Resources/service-presets.json` — общий каталог профилей для меню и сервиса.
- `Resources/setup.py` — первое подключение и восстановление настроек.
- `tests/` — миграция режима, маршрутизация, управление и восстановление после сбоя.
