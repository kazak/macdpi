Tube Switch 1.1.0

- Вместо Instagram добавлен профиль Discord: веб-версия, чат и вложения.
- Twitch и SoundCloud доступны как дополнительные профили; по умолчанию выключены.
- Меню «Сервисы» позволяет включать обход для каждого профиля отдельно.
- Выбранные профили и общий режим сохраняются после перезапуска.

Требования: macOS 13+, Apple Command Line Tools с Python 3.9+.
Приложение Universal: Apple Silicon и Intel.

Голос Discord через UDP не поддерживается. Доступность сервисов зависит от провайдера.
В выключенном режиме локальный прокси продолжает передавать трафик без обработки DPI.

Сборка GitHub Actions по умолчанию имеет ad-hoc-подпись и не нотаризована Apple.
Перед публичным выпуском замените её подписанной и нотаризованной сборкой либо явно
сохраните это ограничение в описании релиза.
