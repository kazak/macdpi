# Проверка перед релизом 1.1.0

Дата: 7 ноября 2026 года.

Проверены исходники, существующая история клона и релизные артефакты.
Использован Gitleaks 8.30.1 с настройками по умолчанию, полной редакцией
секретов в отчётах и обходом вложенных архивов. Утечек не обнаружено.

Дополнительно `scripts/audit.py` проверяет:

- блоки открытых и закрытых ключей, SSH public keys и распространённые форматы API-токенов;
- отсутствие файлов ключей, `.env`, пользовательской конфигурации и логов;
- вложенные ZIP и архив исходников движка внутри приложения;
- при локальном запуске с `--compare-local-runtime` — отсутствие текущего
  рабочего ключа управления во всех проверяемых файлах. Его значение не выводится.

Локальный ключ генерируется на компьютере пользователя и хранится вне репозитория
с правами `0600`. Он не включён в архивы приложения или исходников.
В CI используются ссылки на автоматически создаваемый `github.token`, а не
вписанные в код значения токенов. Сертификаты, ключи подписи и credentials
notarization в репозиторий не добавлены.

## Повторная проверка

```sh
python3 scripts/build.py
python3 scripts/audit.py --artifacts dist/*.zip
gitleaks git --redact --ignore-gitleaks-allow --log-opts=--all .
gitleaks dir --redact --ignore-gitleaks-allow --max-archive-depth 4 dist
```

Проверки включены в workflow CI и создания черновика релиза. Артефакты не загружаются
в GitHub Release, если проверка завершилась с ошибкой.
