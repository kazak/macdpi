# Изменения

## 1.1.0

- Instagram полностью удалён из профилей, быстрых ссылок и интерфейса.
- Добавлен Discord для веб-версии, чата и вложений. Ограничение голосовых каналов явно указано.
- Добавлены отключённые по умолчанию профили Twitch и SoundCloud.
- Новое меню «Сервисы» позволяет выбирать профили по отдельности.
- Меню и сервис используют общий каталог доменов, выбор сохраняется при перезапуске.
- Сохранена совместимость с `mode.json` и сетевой конфигурацией версии 1.0.
- Добавлены скрипт сборки Universal-приложения из фиксированных исходников, контрольные суммы,
  тесты, лицензии и GitHub Actions для черновика релиза.

## 1.0

- Первая локальная версия с переключателем в строке меню и первоначальной настройкой подключения.
